# SparseVLA project website

Anonymous project page for **SparseVLA: Towards Smaller and Faster Vision-Language-Action Models**.

The page includes six real-robot task demonstrations, the method overview, results from the manuscript, and an anonymized paper PDF. Four tasks are evaluated quantitatively; toast and chocolate transfer are supplementary demonstrations. Videos focus on the central robot workspace and omit audio and source metadata.

All assets are served from this directory. There are no external fonts, analytics, embeds, or JavaScript dependencies. Open `index.html` through any static HTTP server. Enable GitHub Pages from `main` / repository root, then share the Anonymous GitHub website mirror during double-blind review.
